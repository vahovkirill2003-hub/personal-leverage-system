# Personal Leverage System
## Specification Stage Acceptance Log v1.0

**Назначение:** append-only реестр проверок и приёмок документов и задач стадий спецификаций и реализации. Прежние записи не редактируются; манифест журнала перевыпускается при каждом предъявлении.
**Статус:** принят пользовательской приёмкой Кирилла 28 августа 2026; действующая версия. Заменяет `16-spec-stage-acceptance-log-v0.md` (внутренний заголовок `v0.8`), который сохраняется и не редактируется.
**Дата:** 28 августа 2026

**Основание мажорной версии — смена контура ведения, а не смена правил.** Записи 1–11 велись по упрощённому контуру `15-spec-stage-process-deviation-v0.md`, где каждая новая запись повышала минорную версию журнала. Записи 12–17 велись **вне репозитория**: канонического репозитория ещё не было либо журнал в него не переносился. С записи 18 ведение переходит в репозиторий, а основанием записи становятся merge-коммит и прогон CI. Три разных контура ведения дают три раздела и три формы таблицы; сводить их к одной форме значило бы переписать принятые записи, что запрещено append-only правилом журнала. Правила приёмки, единственный акцептор и продуктовый baseline настоящей версией не изменяются.
